Python Cleaning Script (clean_leads.py)

import csv
import re
from pathlib import Path

def standardize_phone(phone_raw: str) -> str:
    """Standardizes Indian phone numbers to '+91XXXXXXXXXX'."""
    if not phone_raw:
        return ""
    digits = re.sub(r"\D", "", phone_raw)
    if len(digits) == 12 and digits.startswith("91"):
        digits = digits[2:]
    elif len(digits) == 11 and digits.startswith("0"):
        digits = digits[1:]
    return f"+91{digits}" if len(digits) == 10 else f"+91{digits[-10:]}"

def clean_leads_csv(input_path: str, output_path: str):
    cleaned, seen = [], set()
    with open(input_path, mode="r", encoding="utf-8") as infile:
        reader = csv.DictReader(infile)
        for row in reader:
            name = row.get("Name", "").strip()
            phone = standardize_phone(row.get("Phone", "").strip())
            if (name, phone) not in seen:
                seen.add((name, phone))
                cleaned.append({"Name": name, "Phone": phone})

    with open(output_path, mode="w", newline="", encoding="utf-8") as outfile:
        writer = csv.DictWriter(outfile, fieldnames=["Name", "Phone"])
        writer.writeheader()
        writer.writerows(cleaned)
    return cleaned

if __name__ == "__main__":
    clean_leads_csv("messy_leads.csv", "cleaned_leads.csv")

Automation Logic (n8n Workflow)

End-to-end event-driven architecture connecting Google Forms, ClickUp, Client Confirmation, and VIP Routing.

Workflow Diagram

               │
               ▼

               │

               ▼
   [ Node 4: IF Condition ] ---------> (Is budgetNumber >= 500000?)
         │               │
     TRUE ▼           FALSE ▼
[ Node 5: Slack/WhatsApp Alert ]   [ Node 6: Normal Queue ]
(High-Value VIP Lead to Design)     (Logged for standard follow-up)

1. Trigger

Google Forms Trigger Node (or Webhook): Executes immediately when a prospective client submits an inquiry form.

2. Sequence of Actions

  1. Data Sanitization (Code Node): Cleans phone to +91XXXXXXXXXX and casts budget strings (e.g., "7,00,000" or "7.5 Lakhs") into pure integers.
  2. ClickUp Lead Creation: Generates a task in the Client Leads list with mapped custom fields.
  3. Client Confirmation (Gmail/WhatsApp Cloud API): Sends immediate branded confirmation acknowledging project inquiry.
  4. Conditional Gate (IF Node): Checks if budget is greater than or equal to ₹5,00,000.
  5. High-Priority Alert (Slack / WhatsApp Group): Fires an urgent ping to the 3-person design team channel with lead details and ClickUp link.

3. Where the ₹5 Lakh Conditional Logic Fits

The conditional logic sits after the lead is secured in ClickUp and after the client receives confirmation, but before internal notification alerts. This guarantees:

  • No lead is lost, regardless of budget size.
  • Every client receives immediate professional acknowledgement.
  • The design team is spared from alert fatigue, only being interrupted for high-value VIP projects.

⚠️ What Could Go Wrong & How to Prevent It (Error Handling)

Failure Mode: Unstructured budget input (e.g., client types "To be discussed" or "Around 6L") causing NaN errors in numeric comparison, or transient API rate limits on ClickUp/WhatsApp.

Solution:
1. Defensive Parsing: If the budget string fails numeric conversion, default to a flag_requires_review = true status, which routes the lead directly to the priority alert branch so no high-value client is accidentally dropped.
2. n8n Error Trigger Node: Configure an automated error-catcher workflow that logs failed runs to a backup Google Sheet and pings the administrator immediately on Telegram/Slack with retry options enabled.
